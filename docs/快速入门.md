# 快速入门指南

> **版本**: v2.0.0 | **更新**: 2025-01-17

## 🚀 5分钟上手

### 环境要求
- Python 3.7+
- 2GB+ 内存

### 安装
```bash
pip install airtest pyyaml poco
git clone <项目地址>
cd airtest_framework
```

### 验证
```bash
python3 run_tests.py --help
```

---

## 📱 基础使用

### 1. 准备测试
```bash
# 将 .air 项目放入 tests/ 目录
cp your_test.air tests/
```

### 2. 运行测试
```bash
# 列出测试
python3 run_tests.py list

# 执行测试
python3 run_tests.py run

# 生成报告
python3 run_tests.py run --report
```

### 3. 查看结果
- 报告：`reports/` 目录
- 日志：`logs/` 目录

## 🔧 统一系统使用

### 元素分析
```python
from airtest_framework.unified_analyzer import UnifiedAnalyzer

analyzer = UnifiedAnalyzer()
mappings = analyzer.analyze_elements(airtest_elements, poco_elements)
quality = analyzer.analyze_quality(mappings)
```

### 实时监控
```python
from airtest_framework.unified_monitor import UnifiedMonitor

monitor = UnifiedMonitor()
monitor.start_monitoring(elements)
stats = monitor.get_statistics()
```

### 报告生成
```python
from airtest_framework.unified_reporter import UnifiedReporter

reporter = UnifiedReporter()
html_report = reporter.generate_file_report(data, "analysis", "html")
dashboard = reporter.create_dashboard(data)
```

## ⚙️ 配置

### 基础配置
```yaml
# config.yaml
analysis:
  similarity_threshold: 0.8
  max_elements: 1000

monitoring:
  enabled: true
  interval: 1.0

reporting:
  formats: ["html", "json"]
  output_dir: "reports"
```

### 高级配置
```python
from airtest_framework.unified_config import UnifiedConfigManager

config_manager = UnifiedConfigManager()
config_manager.load_config("config.yaml")
config_manager.update_analysis_config({"similarity_threshold": 0.9})
```

## 🔍 故障排除

### 常见问题

**设备连接失败**
```bash
# 检查设备连接
adb devices
# 重启ADB
adb kill-server && adb start-server
```

**元素定位失败**
- 检查元素选择器语法
- 确认页面已完全加载
- 调整相似度阈值

**性能问题**
- 减少监控频率
- 启用缓存机制
- 限制并发数量

### 日志分析
```bash
# 查看详细日志
tail -f logs/airtest_framework.log

# 过滤错误信息
grep "ERROR" logs/airtest_framework.log
```

## 💡 最佳实践

### 测试组织
- 按功能模块组织测试用例
- 使用描述性的测试名称
- 保持测试用例独立性

### 元素定位
- 优先使用稳定的元素属性
- 避免使用绝对坐标
- 设置合理的等待时间

### 报告管理
- 定期清理历史报告
- 使用标签分类测试结果
- 配置自动化报告推送
