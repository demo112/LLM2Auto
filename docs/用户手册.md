## 1. 快速开始

### 1.1 环境要求

**系统要求**:
- Python 3.7 或更高版本
- macOS、Windows 或 Linux 操作系统
- 至少 2GB 可用内存

**依赖软件**:
- ADB (Android Debug Bridge) - 用于Android设备连接
- Xcode Command Line Tools - 用于iOS设备连接 (仅macOS)

### 1.2 安装步骤

1. **安装Python依赖**:
```bash
pip install airtest
pip install pyyaml
pip install poco
```

2. **克隆项目**:
```bash
git clone <项目地址>
cd airtest_framework
```

3. **验证安装**:
```bash
python3 run_tests.py --help
```

### 1.3 第一个测试

1. **准备测试用例**:
   - 将您的 `.air` 测试项目放在 `tests/` 目录下
   - 确保测试项目包含 `metadata.yaml` 文件

2. **运行测试**:
```bash
# 列出所有测试
python3 run_tests.py list

# 执行所有测试
python3 run_tests.py run

# 生成报告
python3 run_tests.py run --report
```

3. **查看结果**:
   - 测试报告将生成在 `reports/` 目录
   - 日志文件保存在 `logs/` 目录

## 4. 融合测试

### 4.1 融合测试概述

融合测试是框架的核心特性，它能够：
- 自动对齐Airtest和Poco测试步骤
- 提供多种执行策略
- 实现智能回退机制
- 生成详细的融合测试报告

### 4.2 融合测试使用

#### 4.2.1 基本使用

**运行融合测试**:
```bash
python3 run_fusion_tests.py
```

**详细模式**:
```bash
python3 run_fusion_tests.py --verbose
```

**调试模式**:
```bash
python3 run_fusion_tests.py --debug
```

#### 4.2.2 执行策略

**Poco优先策略** (默认):
```bash
python3 run_fusion_tests.py --strategy poco_first
```

**Airtest优先策略**:
```bash
python3 run_fusion_tests.py --strategy airtest_first
```

**并行执行策略**:
```bash
python3 run_fusion_tests.py --strategy parallel
```

#### 4.2.3 测试用例准备

融合测试需要同时准备Airtest和Poco版本的测试用例:

```
tests/mobile/
├── test_case_demo.air/          # Airtest版本
│   ├── test_case_demo.py
│   └── metadata.yaml
└── test_case_demo_poco.air/     # Poco版本
    ├── test_case_demo_poco.py
    └── metadata.yaml
```

### 4.3 步骤对齐

#### 4.3.1 自动对齐

框架会自动分析两个脚本的操作步骤并进行对齐:

```python
# Airtest步骤示例
touch("login_button.png")
text("username")
touch("password_field.png")

# Poco步骤示例  
poco("login_button").click()
poco("username_input").set_text("username")
poco("password_input").click()
```

#### 4.3.2 对齐规则

- **点击操作**: `touch()` ↔ `click()`
- **文本输入**: `text()` ↔ `set_text()`
- **等待操作**: `wait()` ↔ `wait_for_appearance()`
- **断言操作**: `assert_exists()` ↔ `wait_for_appearance()`

### 4.4 融合测试报告

融合测试会生成专门的报告，包含:
- 步骤对齐结果
- 执行策略使用情况
- 回退统计
- 详细的步骤执行日志

## 5. 智能工具

### 5.1 智能图标匹配

#### 5.1.1 多状态图标处理

智能图标匹配工具可以处理具有多种状态的UI元素:

```python
from airtest_framework.utils.smart_icon_matcher import SmartIconMatcher

matcher = SmartIconMatcher()

# 定义收藏按钮的多个状态
favorite_states = [
    "favorite_selected.png",    # 选中状态（红心）
    "favorite_unselected.png"   # 未选中状态（空心）
]

# 无论当前是什么状态，都能成功点击
if matcher.multi_state_touch(favorite_states):
    print("成功点击收藏按钮")
else:
    print("未找到收藏按钮")
```

#### 5.1.2 状态检测和切换

```python
# 定义开关的状态映射
switch_states = {
    "on": "switch_on.png",      # 开启状态
    "off": "switch_off.png"     # 关闭状态
}

# 检测当前状态
current_state = matcher.get_current_state(switch_states)
print(f"当前开关状态: {current_state}")

# 切换到指定状态
target_state = "on"
if matcher.switch_to_state(target_state, switch_states):
    print(f"成功切换到{target_state}状态")
else:
    print(f"切换到{target_state}状态失败")
```

#### 5.1.3 高级功能

**相似度阈值调整**:
```python
matcher = SmartIconMatcher(threshold=0.8)  # 默认0.7
```

**区域限制**:
```python
# 在指定区域内查找
region = (100, 100, 500, 400)  # (x, y, width, height)
matcher.multi_state_touch(icon_states, region=region)
```

**超时设置**:
```python
# 设置查找超时时间
matcher.multi_state_touch(icon_states, timeout=15.0)
```

## 7. 故障排除

### 7.1 常见问题

#### 7.1.1 设备连接问题

**问题**: 设备无法连接
```
错误: Device connection failed
```

**解决方案**:
1. 检查USB连接和驱动
2. 确认设备已启用USB调试
3. 重启ADB服务:
```bash
adb kill-server
adb start-server
adb devices
```

#### 7.1.2 测试发现问题

**问题**: 无法发现测试用例
```
错误: No test cases discovered
```

**解决方案**:
1. 检查测试目录路径是否正确
2. 确认 `.air` 项目结构完整
3. 验证 `metadata.yaml` 文件格式:
```bash
python3 -c "import yaml; yaml.safe_load(open('metadata.yaml'))"
```

#### 7.1.3 执行超时问题

**问题**: 测试执行超时
```
错误: Test execution timeout
```

**解决方案**:
1. 增加超时时间:
```bash
python3 run_tests.py run --timeout 600
```
2. 检查设备性能和网络状况
3. 优化测试脚本中的等待时间

#### 7.1.4 Poco驱动问题

**问题**: Poco驱动未初始化
```
错误: Poco driver was not initialized
```

**解决方案**:
1. 确认应用支持Poco
2. 检查Poco服务是否启动
3. 验证应用权限设置

### 8.2 代码规范

#### 8.2.1 脚本结构

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
测试用例: 用户登录功能
作者: 张三
创建时间: 2025-10-13
"""

from airtest.core.api import *
from poco.drivers.android.uiautomation import AndroidUiautomationPoco

# 初始化
auto_setup(__file__)
poco = AndroidUiautomationPoco(use_airtest_input=True, screenshot_each_action=False)

def setup():
    """测试前置条件"""
    # 启动应用
    start_app("com.example.app")
    sleep(2)

def test_valid_login():
    """测试有效登录"""
    try:
        # 点击登录按钮
        touch(Template("login_button.png"))
        
        # 输入用户名
        touch(Template("username_field.png"))
        text("testuser")
        
        # 输入密码
        touch(Template("password_field.png"))
        text("password123")
        
        # 提交登录
        touch(Template("submit_button.png"))
        
        # 验证登录成功
        assert_exists(Template("home_page.png"), "登录成功，进入主页")
        
    except Exception as e:
        log(f"测试失败: {e}")
        raise

def teardown():
    """测试后清理"""
    # 关闭应用
    stop_app("com.example.app")

if __name__ == "__main__":
    setup()
    test_valid_login()
    teardown()
```

#### 8.2.2 错误处理

```python
def robust_touch(template, timeout=10, retry=3):
    """健壮的点击操作"""
    for i in range(retry):
        try:
            if exists(template):
                touch(template)
                return True
        except Exception as e:
            log(f"点击失败 (尝试 {i+1}/{retry}): {e}")
            sleep(1)
    return False

def safe_text_input(field_template, text_content):
    """安全的文本输入"""
    try:
        # 清空现有内容
        touch(field_template)
        keyevent("KEYCODE_CTRL_A")
        keyevent("KEYCODE_DEL")
        
        # 输入新内容
        text(text_content)
        
        # 验证输入
        sleep(1)
        return True
    except Exception as e:
        log(f"文本输入失败: {e}")
        return False
```
