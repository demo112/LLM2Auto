## 1. 问题背景

在UI自动化测试中，经常遇到同一个图标有不同状态的情况，比如：
- 收藏按钮：选中（红心）vs 未选中（空心）
- 开关按钮：开启 vs 关闭
- 导航标签：选中 vs 未选中
- WiFi图标：连接 vs 断开 vs 连接中

传统的Airtest录制只能捕获当时的图标状态，无法处理状态变化，导致测试用例不够健壮。

## 2. 解决方案

我们提供了 `SmartIconMatcher` 智能图标匹配工具，可以有效解决这个问题。

## 3. 核心功能

### 1. 多状态图标点击
无论图标当前是什么状态，都能成功点击。

```python
from airtest_framework.utils.smart_icon_matcher import SmartIconMatcher

matcher = SmartIconMatcher()

# 定义图标的多个状态
favorite_states = [
    "favorite_selected.png",    # 选中状态
    "favorite_unselected.png"   # 未选中状态
]

# 多状态点击 - 自动匹配任意状态并点击
if matcher.multi_state_touch(favorite_states):
    print("成功点击收藏按钮")
```

### 2. 状态检测和切换
检测当前状态并切换到目标状态。

```python
# 定义状态映射
switch_states = {
    "on": "switch_on.png",
    "off": "switch_off.png"
}

# 获取当前状态
current_state = matcher.get_current_state(switch_states)
print(f"当前状态: {current_state}")

# 切换到指定状态
if matcher.toggle_state(switch_states, "on"):
    print("成功切换到开启状态")
```

### 3. 状态等待和验证
等待特定状态出现并进行验证。

```python
# 等待任意状态出现
found_state = matcher.wait_for_any_state(favorite_states, timeout=10.0)
if found_state:
    print(f"找到状态: {found_state}")

# 验证当前状态
if matcher.smart_assert_state(switch_states, "on"):
    print("状态验证成功")
```

## 4. 高级功能

### 4.1 使用IconStateManager管理多个图标

```python
from airtest_framework.utils.smart_icon_matcher import IconStateManager

manager = IconStateManager()

# 定义多个图标的状态
manager.define_icon_states("favorite", {
    "selected": "favorite_selected.png",
    "unselected": "favorite_unselected.png"
})

manager.define_icon_states("wifi", {
    "connected": "wifi_connected.png",
    "disconnected": "wifi_disconnected.png",
    "connecting": "wifi_connecting.png"
})

# 使用图标
manager.click_icon("favorite")  # 自动处理多状态
manager.set_icon_state("wifi", "connected")  # 设置到指定状态
current_state = manager.get_icon_state("favorite")  # 获取当前状态
```

### 实际应用：底部导航栏处理

```python
def navigate_to_tab(manager, tab_name, target_state="selected"):
    """导航到指定标签页"""
    # 检查是否已经在目标页面
    if manager.get_icon_state(tab_name) == target_state:
        return True
    
    # 点击标签
    if manager.click_icon(tab_name):
        sleep(1)  # 等待状态变化
        return manager.get_icon_state(tab_name) == target_state
    
    return False

# 定义导航栏状态
manager.define_icon_states("home_tab", {
    "selected": "home_selected.png",
    "unselected": "home_unselected.png"
})

# 导航到首页
if navigate_to_tab(manager, "home_tab"):
    print("成功导航到首页")
```

### 4.2 便捷函数

为了简化使用，我们还提供了便捷函数：

```python
from airtest_framework.utils.smart_icon_matcher import (
    multi_state_touch, 
    wait_for_any_icon_state, 
    toggle_icon_state
)

# 直接使用便捷函数
button_states = ["button_normal.png", "button_pressed.png"]
multi_state_touch(button_states, timeout=5.0)

# 等待状态
found_state = wait_for_any_icon_state(button_states, timeout=5.0)

# 切换状态
states = {"on": "switch_on.png", "off": "switch_off.png"}
toggle_icon_state(states, "on")
```

## 5. 最佳实践

### 5.1 图片命名规范
建议使用有意义的命名规范：
```
icon_name_state.png
例如：
- favorite_selected.png
- favorite_unselected.png
- wifi_connected.png
- wifi_disconnected.png
```

### 5.2 状态定义策略
在测试开始时统一定义所有图标状态：

```python
def setup_icon_states(manager):
    """设置所有图标状态定义"""
    # 底部导航
    manager.define_icon_states("home_tab", {
        "selected": "home_selected.png",
        "unselected": "home_unselected.png"
    })
    
    manager.define_icon_states("search_tab", {
        "selected": "search_selected.png",
        "unselected": "search_unselected.png"
    })
    
    # 功能按钮
    manager.define_icon_states("favorite", {
        "selected": "favorite_selected.png",
        "unselected": "favorite_unselected.png"
    })
    
    return manager
```

### 5.3 错误处理
添加适当的错误处理：

```python
try:
    if manager.click_icon("favorite"):
        print("操作成功")
    else:
        print("操作失败：未找到图标")
except ValueError as e:
    print(f"配置错误: {e}")
except Exception as e:
    print(f"未知错误: {e}")
```

### 5.4 超时设置
根据应用响应速度设置合适的超时时间：

```python
# 快速响应的应用
matcher.multi_state_touch(states, timeout=3.0)

# 较慢的应用或网络操作
matcher.wait_for_any_state(states, timeout=15.0)
```

### 5.5 配置参数

#### 匹配阈值 (threshold)
控制图像匹配的精确度，范围0.0-1.0：
- 0.8-0.9：推荐值，平衡准确性和容错性
- 0.9-1.0：高精确度，适用于图标差异较小的情况
- 0.6-0.8：低精确度，适用于图标变化较大的情况

```python
# 设置匹配阈值
matcher.multi_state_touch(states, threshold=0.85)
```

#### 超时时间 (timeout)
等待图标出现的最大时间：
```python
# 短超时：快速失败
matcher.wait_for_any_state(states, timeout=3.0)

# 长超时：等待加载
matcher.wait_for_any_state(states, timeout=30.0)
```

#### 重试次数 (max_attempts)
状态切换的最大尝试次数：
```python
# 增加重试次数以提高成功率
matcher.toggle_state(states, "target", max_attempts=5)
```

## 6. 故障排除

### 6.1 图标识别失败
- 检查图片路径是否正确
- 调整匹配阈值
- 确认图片分辨率和设备匹配
- 检查图标是否被遮挡

### 6.2 状态切换失败
- 增加状态切换后的等待时间
- 检查状态定义是否完整
- 确认点击位置是否正确
- 增加重试次数

### 6.3 性能优化
- 减少不必要的状态检查
- 使用合适的超时时间
- 缓存常用的Template对象
- 避免频繁的状态切换
