# Airtest 通用自动化测试框架演示项目

这是一个完整的 Airtest 自动化测试框架演示项目，展示了如何将现有的 `.air` 项目集成到统一的测试框架中。

## 快速开始

1. **运行演示脚本**:
   ```bash
   python demo_usage.py
   ```

2. **快速执行测试**:
   ```bash
   python quick_run.py
   ```

3. **批量执行测试**:
   ```bash
   python batch_run.py
   ```

## 项目结构

```
演示项目/
├── airtest_framework/          # 框架核心代码
├── tests/                      # 测试项目目录
│   ├── mobile/                 # 移动端测试
│   ├── web/                    # Web测试
│   └── api/                    # API测试
├── config/                     # 配置文件
├── reports/                    # 测试报告
├── logs/                       # 日志文件
├── demo_usage.py              # 演示脚本
├── quick_run.py               # 快速运行脚本
├── batch_run.py               # 批量运行脚本
└── README_框架使用指南.md      # 详细使用指南
```

## 核心特性

- ✅ **零代码集成**: 直接复制 `.air` 项目，按规则重命名即可使用
- 🔍 **智能发现**: 自动发现和分类测试项目
- ⚙️ **灵活配置**: 支持多环境配置管理
- 📊 **完整报告**: HTML/JSON/XML 多格式报告
- 🏷️ **标签管理**: 支持按标签、优先级、分类过滤
- 📝 **自动注册**: 支持装饰器方式注册测试用例
